# Presentation source package

Created 19 October 2026 for preparing a presentation in ChatGPT Work.

- Deliverable: `SPAI_GMRES_IR_Presentation_Sources.zip`.
- 317 source files; 613,710 compressed bytes, 1,917,177 original bytes.
- Includes the tested implementation, methods, historical/final benchmark
  reports and statistics, 24 figure/dataflow assets, 25 CSV tables, 120 final
  saved Decimal80 sidecars, profiling CSVs/manifests, and literature references.
- Root README maps the presentation topics to evidence and explains which
  sources take precedence, historical exclusions, missing information and
  limits on numerical/performance claims.
- Two dated/misleading architecture/workflow SVGs are omitted; the package has
  a source-checked Mermaid CPU/GPU dataflow and the original diagram audits.
- Non-relinked Stage A profiles are excluded from after-change evidence.
- No Git data, profiler binaries/databases, large solver snapshots, generated
  executables or finished presentation are included. No experiment was rerun.
- The code-submission ZIP and all existing project source files are unchanged.

Validation: archived source SHA-256 identities, all packaged hashes and ZIP CRC,
unique paths, 120 final CSV medians, 120 accepted configuration verdicts and 360
measured assessments checked. File-selection checks confirmed no excluded
profiler binaries, stale Stage A traces or deck files. Exact integrity metadata
is in `package_integrity.json`. Recreate with `python presentation/prepare_sources.py`.

This package does not contain full-text research PDFs, genuine execution
screenshots, a personal project narrative or assignment-specific presentation
requirements. Those gaps are stated in its README rather than filled with
unsupported claims.
